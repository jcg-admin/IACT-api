================================================================================
  IACT API — VARIABLES DE ENTORNO (.env)
  Fuente única de verdad para Django y scripts de provisioning
================================================================================

  PRINCIPIO
  ──────────
    Un solo archivo .env en la raíz del proyecto.
    Django lo lee directamente (python-decouple / django-environ).
    Los scripts de provisioning lo sourcean como adapter.

    .env
     │
     ├──► Django (config/settings/base.py)
     │       DATABASES['default'] usa DB_*
     │       DATABASES['ivr']     usa IVR_DB_*
     │
     ├──► scripts/config/postgres.conf
     │       DB_HOST     → POSTGRES_HOST
     │       DB_PORT     → POSTGRES_PORT
     │       DB_NAME     (sin cambio)
     │       DB_USER     (sin cambio)
     │       DB_PASSWORD (sin cambio)
     │
     └──► scripts/config/mariadb.conf
             IVR_DB_HOST     → MARIADB_HOST
             IVR_DB_PORT     → MARIADB_PORT
             IVR_DB_NAME     → DB_NAME
             IVR_DB_USER     → DB_USER
             IVR_DB_PASSWORD → DB_PASSWORD

  VARIABLES COMPLETAS
  ────────────────────

    SECCIÓN DJANGO
    ─────────────────────────────────────────────────────────────────
    Variable                      Usado por         Ejemplo
    ─────────────────────────────────────────────────────────────────
    DJANGO_SETTINGS_MODULE        Django            config.settings.development
    SECRET_KEY                    Django (requerido) django-insecure-...
    DEBUG                         Django            True
    ALLOWED_HOSTS                 Django            localhost,127.0.0.1

    SECCIÓN POSTGRESQL (Django default DB)
    ─────────────────────────────────────────────────────────────────
    Variable                      Usado por         Ejemplo
    ─────────────────────────────────────────────────────────────────
    DB_NAME                       Django + PG conf  iact_analytics
    DB_USER                       Django + PG conf  django_user
    DB_PASSWORD                   Django + PG conf  django_pass
    DB_HOST                       Django + PG conf  127.0.0.1
    DB_PORT                       Django + PG conf  5432

    SECCIÓN MARIADB (IVR Legacy, READ-ONLY)
    ─────────────────────────────────────────────────────────────────
    Variable                      Usado por         Ejemplo
    ─────────────────────────────────────────────────────────────────
    IVR_DB_NAME                   Django + MDB conf ivr_legacy
    IVR_DB_USER                   Django + MDB conf django_user
    IVR_DB_PASSWORD               Django + MDB conf django_pass
    IVR_DB_HOST                   Django + MDB conf 127.0.0.1
    IVR_DB_PORT                   Django + MDB conf 3306

    SECCIÓN PROVISIONING (solo scripts — Django no las lee)
    ─────────────────────────────────────────────────────────────────
    Variable                      Usado por         Ejemplo
    ─────────────────────────────────────────────────────────────────
    MARIADB_VERSION               mariadb.conf      11.4
    POSTGRES_VERSION              postgres.conf     16
    DB_ROOT_PASSWORD              mariadb install   root_pass_CHANGE_ME
    POSTGRES_PASSWORD             postgres install  postgres_pass_CHANGE_ME

  VARIABLES PROHIBIDAS (CNST v2.2.1)
  ────────────────────────────────────
    ✗  EMAIL_*        CNST-001
    ✗  SENTRY_*       CNST_TECNICAS
    ✗  REDIS_*        CNST_TECNICAS
    ✗  CELERY_*       CNST-004 + CNST_TECNICAS
    ✗  CHANNELS_*     CNST-004

  GESTIÓN EN GIT
  ───────────────
    .env         ──► TRACKEADO  (plantilla con valores placeholder)
    .env.local   ──► IGNORADO   (credenciales reales, gitignored)

    Para producción o entornos reales:
      cp .env .env.local
      # editar .env.local con valores reales
      export $(cat .env.local | xargs)
